# 卡牌修仙传 · 图鉴自动抓取 & HTML 攻略生成工具

在游戏【图鉴】界面自动**逐张点击卡牌 → 截图 → 右侧说明文字超长时自动下滑并无缝拼接 → 左侧列表自动下滑直到最后一张**，
然后用**本地离线 OCR（免费，无需 API Key）**把文字转成结构化数据，生成可直接发布到 GitHub Pages 的 HTML 攻略。

> 适用环境：Windows 10/11 · 游戏 **1920×1080 全屏 / 无边框全屏**（其他 16:9 分辨率会自动等比缩放）

---

## 一、首次安装（只需一次）

1. 安装 **Python 3.10+**：<https://www.python.org/downloads/>
   安装界面务必勾选 **“Add python.exe to PATH”**。
2. 双击 **`一键安装依赖.bat`**
   会自动安装 `mss`、`numpy`、`Pillow`、`rapidocr`、`onnxruntime`，并预下载约 20MB 的 PP-OCRv5 中文模型。
   （官方源失败会自动切换清华镜像。）

## 二、开始抓取

1. 打开游戏 → 【图鉴】→【卡牌】→ 左侧选好分类（例如 **【感悟&心法】**）。
2. 双击 **`开始抓取.bat`**，选择 `1`，然后在 **5 秒倒计时内切回游戏画面**，松开鼠标。
3. 脚本会自动：
   - 识别当前分类（顶部页签 + 左侧子分类），数据存到 `captures/kapai_ganwu_xinfa/`
   - 把左侧列表滚到顶部，逐张点击卡牌（已抓取的会自动跳过）
   - 截取：卡牌缩略图、右侧大图标、标题、**完整正文长图**（超出一屏时自动下滑、像素级对齐拼接）
   - 左侧一屏抓完后自动下滑，直到最后一张（最后一行不满 6 张也没问题）
4. 第 1 阶段结束后会提示 **“鼠标已释放”**，之后的 OCR 识别在后台进行，你可以自由使用电脑。
5. 完成后自动用浏览器打开 `docs/index.html`。

### 热键

| 按键 | 作用 |
|---|---|
| **F9** | 暂停 / 继续 |
| **F10** 或 **F12** | 停止并保存进度（下次运行自动续抓） |
| 鼠标甩到屏幕**左上角** | 紧急停止 |
| 运行中手动移动鼠标 | 自动暂停，切回游戏后按 F9 继续 |

### 菜单选项

- `1` 开始 / 继续抓取（推荐，支持断点续抓）
- `2` 从头重新抓取（删除该分类旧进度）
- `3` 高精度 OCR（PP-OCRv5 server 大模型，更准但更慢，首次需额外下载模型）
- `4` **补全未获得卡牌**（见下一节）

## 🔒 未获得的卡牌：收录、标记、以后补全

图鉴里没获得的卡牌是浅色底板（如上图的「焚霄诀」「九死功」「不动经」）。工具会：

1. **照样收录**：点开它，保存卡牌图和游戏里能看到的说明，写进攻略。
2. **标记 🔒 未获得**：网页上卡牌底部显示「🔒 未获得」，详情页有提示框，
   工具栏可按「已获得 / 🔒 未获得」筛选；Markdown 里标题后面带「（🔒 未获得）」。
3. **以后补全**：在游戏里获得新卡牌后，打开同一分类，运行 `开始抓取.bat` → **`4`**。
   脚本会从头滑到尾，但**只点击“之前未获得、现在已获得”的卡**，其余全部跳过，几十秒就跑完。
   补抓的卡在网页上显示红色「新」角标，可用「★ 新获得」筛选。
4. **不会覆盖你的校对**：重新生成数据时，截图没变的条目直接沿用 `docs/data` 里已有的文字（包括你手动改过的），
   只有新抓的卡才重新 OCR。

> **已经用旧版本跑过的？** 把新压缩包解压**覆盖**到原来的文件夹（不会动你的 `captures/` 和 `docs/data/`），
> 然后运行 `开始抓取.bat` → `1`。旧版漏掉的未获得卡牌会被自动补上，已抓取的卡不会重复点击。

### 抓取下一个分类

在游戏里切换到下一个分类（如【技能&口诀】），再次运行 `开始抓取.bat` 即可。
每个分类单独保存，网页上会自动出现新的分类页签。

## 三、校对文字（推荐）

OCR 对游戏的楷体字识别率很高（实测卡名 24/24 全对，正文单行置信度 95%~99.7%），
脚本还会自动修正常见楷体形近字（如 `途泾→途径`、`义定→必定`）。仍建议快速过一遍：

1. 打开 `docs/index.html`，置信度偏低的卡牌右上角有 **黄色圆点**，可点工具栏「建议核对」筛选。
2. 点击右侧「**对照原图校对**」，上面是游戏原图（自动拼接的完整长图），下面是可编辑文字。
3. 修改后点「保存本条修改」（保存在浏览器里，卡牌左上角出现绿色圆点）。
4. 全部改完点「**下载修正 JSON**」，把下载的 `kapai_ganwu_xinfa.json` 覆盖到 `docs/data/`，
   然后运行 `重新生成HTML攻略.bat` → `1`，修改就永久写入网页了。

> 注意：`重新生成HTML攻略.bat` → `2`（全部重新 OCR）会覆盖你手动修改过的文字；旧文件会自动备份到 `docs/data_backup/`。
> 平时抓取 / 补全只会识别新内容，不会覆盖已有文字。
> 如果在网页里校对过某张未获得的卡、之后它被补全重抓，浏览器里的旧校对会自动失效（避免把旧内容盖到新内容上）。

## 四、发布到 GitHub Pages

1. 运行 `重新生成HTML攻略.bat` → `3` 生成**发布版**（隐藏 OCR 置信度和校对按钮）。
2. 新建 GitHub 仓库，把整个文件夹上传（`captures/` 是原始截图，已在 `.gitignore` 中排除）。
3. 仓库 **Settings → Pages → Build and deployment**：Source 选 `Deploy from a branch`，
   Branch 选 `main`，文件夹选 **`/docs`**，保存。
4. 一两分钟后即可通过 `https://你的用户名.github.io/仓库名/` 访问攻略。

网页功能：分类页签、仿游戏图鉴双栏布局、全文列表视图、全文搜索（名称/效果/获取途径）、
键盘 ← → 翻看、一键复制条目文字、导出 Markdown（另有 `docs/markdown/*.md` 自动生成）。

## 五、常见问题

**点击游戏没有反应？**
游戏若以管理员身份运行，Windows 会拦截普通程序的鼠标模拟。请右键 `开始抓取.bat` → **以管理员身份运行**。

**提示“当前画面不像图鉴界面”？**
确认游戏是 1920×1080 全屏且停留在图鉴界面；多显示器时请让游戏位于主显示器，
或用命令行指定：`python capture_tujian.py --monitor 2`。

**分类识别错误？**
手动指定：`python capture_tujian.py --category "卡牌/感悟&心法"`

**想先确认识别效果、不动鼠标？**
在游戏里按截图键保存一张 1920×1080 截图，然后：
`python capture_tujian.py --test-image 截图.png`
会输出画面校验、分类识别、所有卡名以及右侧正文的 OCR 与段落结构，并在 `selftest_output/` 保存裁剪图。

**中途停了 / 出错了？**
直接再次运行 `开始抓取.bat` → `1`，已抓取的卡牌会自动跳过。

## 文件说明

```
capture_tujian.py        主程序：自动点击 / 滚动 / 截图拼接 / OCR / 结构化
build_html.py            把 docs/data/*.json 生成 docs/index.html 和 Markdown
requirements.txt         Python 依赖
一键安装依赖.bat          安装依赖 + 预下载 OCR 模型
开始抓取.bat              开始 / 继续抓取
重新生成HTML攻略.bat      只重建网页 / 重新 OCR / 生成发布版
captures/<分类>/          原始截图与进度（progress.json），不需要上传 GitHub
docs/                    GitHub Pages 发布目录
  index.html             攻略网页（数据已内嵌，可直接双击打开）
  data/<分类>.json        结构化数据（名称、状态 已获得/未获得、段落、【小标题】、图片路径、置信度、获得时间）
  assets/<分类>/          cards 卡牌图 · icons 大图标 · details 校对用完整长图
  markdown/<分类>.md      Markdown 版攻略
```

### 命令行参数

```
python capture_tujian.py [--fresh | --update-locked] [--high-accuracy] [--delay 5] [--monitor 1]
                         [--category "卡牌/感悟&心法"] [--capture-only] [--no-open]
python capture_tujian.py --ocr-only [--force-ocr] [--slug kapai_ganwu_xinfa] [--high-accuracy]
python capture_tujian.py --test-image 截图.png
python build_html.py [--publish]
```
